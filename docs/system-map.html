Two processes. The simulation process runs Ben's newer engine with our memory agent swapped in by one rebind and two small hooks (names and food value). The proxy process holds only the model call. The run folder on disk is what every analysis tool reads. The older engine stays only to re-run the graded anchor_v1 worlds.
